# PixelNorte

Sitio web institucional de PixelNorte, desarrollado como trabajo práctico de Laboratorio Full Stack I.

## Objetivo

Desarrollar un sitio web institucional aplicando buenas prácticas de diseño web, estructura semántica en HTML5 y estilos responsivos mediante CSS3.

## Tecnologías

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Mobile First

## Características

- Diseño responsive
- Estructura semántica
- Navegación intuitiva
- Compatibilidad con dispositivos móviles
- Organización modular del código

## Estructura

- `index.html` - Página principal
- `style.css` - Hoja de estilos
